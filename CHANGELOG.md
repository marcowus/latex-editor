# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-09-19

### Added

- Public release documentation, examples, screenshots, and product-tour GIF.
- Apache-2.0 license, citation metadata, contribution guidance, security policy, and issue forms.
- Local-only server binding by default through LATEX_EDITOR_HOST.
- Project metadata for GitHub discovery and package consumers.

### Included capabilities

- Multi-file LaTeX workspace, preview, source navigation, and project ZIP workflow.
- Mathematical writing tools and optional structured LLM actions.
- TAC-oriented writing shortcuts for control-paper workflows.

### Known boundaries

- The in-app preview is not a substitute for a native TeX build used for publication.
- External LLM calls require the user's own provider credentials and appropriate data-handling judgment.
