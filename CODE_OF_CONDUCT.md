# Code of Conduct

We want this project to be a useful and respectful place for researchers, students, engineers, and maintainers.

## Expected behavior

- Discuss ideas and implementation details in good faith.
- Give feedback about code, documents, and evidence rather than people.
- Protect confidential manuscripts, credentials, and personal information.
- Welcome contributors with different technical backgrounds and writing conventions.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing another person's credentials, unpublished work, or private correspondence.
- Deliberately misrepresenting results, benchmark outcomes, or the capabilities of this software.

## Reporting

Use GitHub's private vulnerability-reporting facility when available for security or privacy incidents. For other conduct concerns, open a minimal issue without sensitive material and request a private contact channel.
