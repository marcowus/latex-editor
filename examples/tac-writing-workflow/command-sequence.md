# Suggested command sequence

1. Use /tac-thesis to identify the one main thesis and its claim boundaries.
2. Use /tac-intro-distill to organize the problem, bottleneck, mechanism, and required evidence.
3. Use /tac-theorem-story only after the actual assumptions and mathematical target are known.
4. Use /tac-notation-audit before finalizing any theorem or experiment section.
5. Use /tac-review after independent evidence has been collected.

Do not use a generated command response as evidence that a theorem, a benchmark, or a journal submission is valid.
