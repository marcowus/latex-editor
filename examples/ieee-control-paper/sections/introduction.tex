\section{Introduction}

Technical manuscripts are easier to revise when the argument structure and file structure agree. This template keeps the introduction separate from the main entry point so authors can evolve it without coupling every edit to the bibliography or theorem sections.

The real manuscript should answer four questions in order:
\begin{enumerate}
  \item What controlled system and operating setting are in scope?
  \item What precise limitation prevents current methods from meeting the target?
  \item What mechanism addresses that limitation?
  \item Which theorem, experiment, or deployment evidence supports each claim?
\end{enumerate}

For foundational state-space context, see \cite{kalman1960}.
