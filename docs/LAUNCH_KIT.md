# Launch kit

This file contains ready-to-post copy. Do not paste credentials, unpublished manuscripts, or private screenshots into any community post.

## Chinese launch post

我开源了 LaTeX Editor：一个面向控制、自动化与工程论文作者的 AI 辅助 LaTeX 工作台。

它把多文件 LaTeX 工程、源码与预览定位、公式/表格/引用工具、工程 ZIP，以及可选的结构化 AI 写作动作放在同一套本地工作区中。当前版本还提供了面向控制论文写作的论题、引言、定理链、符号审计和审稿快捷指令。

我正在寻找第一批真实用户：如果你正在维护 IEEE 风格、多文件或中英文 LaTeX 论文工程，欢迎试用并提交一个可复现的 Issue。最希望它替你省掉哪一步排版、修改或工程管理工作？

仓库：https://github.com/marcowus/latex-editor

## English launch post

I open-sourced LaTeX Editor, an AI-assisted local workspace for technical-paper writing.

It combines multi-file LaTeX projects, source-to-preview navigation, math/table/citation tools, project ZIP workflows, and optional structured LLM actions. The first release includes research-writing shortcuts aimed at control and engineering manuscripts.

I am looking for early users who maintain IEEE-style, bilingual, or multi-file LaTeX papers. A minimal reproducible issue is especially valuable: which writing, formatting, or project-management step should the tool eliminate for you?

Repository: https://github.com/marcowus/latex-editor

## Channel fit

- Start with control, automation, engineering, and LaTeX-writing communities where a multi-file paper workflow is already a painful problem.
- Use GitHub Issues and Discussions for durable feedback.
- Use a tutorial-style Zhihu or Bilibili post that demonstrates one workflow end to end rather than a generic feature list.
- For English communities, follow each community's self-promotion rules before posting.
